# instagram-agent-skills

13 Claude skills that run the @warmnode Instagram ("Rent a friend for coffee & deep talks") for someone with almost no time. Each one hands back finished, copy-ready work.

| Command | What it does |
|---|---|
| `/ig-plan` | Plans the week: what to post, when, and a 15-minute daily routine |
| `/ig-viral` | 10 high-potential post ideas with hooks |
| `/ig-carousel` | Writes a carousel **and renders the 1080x1350 slide images** |
| `/ig-reel` | Faceless reel script: hook, on-screen text, shots, audio |
| `/ig-caption` | Caption with a strong first line, question and hashtags |
| `/ig-story` | Story frames with polls and question stickers |
| `/ig-profile` | Scores your profile out of 100 and rewrites the bio |
| `/ig-comment` | Real comments to leave on bigger accounts |
| `/ig-reply` | Replies to comments on your posts |
| `/ig-dm` | Welcome DMs, collab pitches and follow-ups |
| `/ig-repurpose` | One post into a reel, carousel, stories, Threads, TikTok, Shorts |
| `/ig-human` | Rewrites anything that sounds like AI |
| `/ig-audit` | Reads your insights and tells you what to do next |

## The 30-minute week
1. Once a week: `/ig-plan`, then `/ig-carousel` x2 and `/ig-reel` x2. Schedule all four in Instagram.
2. Daily, 10-15 minutes: `/ig-reply` for comments, `/ig-comment` on 5-10 bigger accounts, a quick `/ig-story`.
3. Every Sunday: `/ig-audit` with your insights screenshots.

## Install in Claude
Each folder is one skill. Zip each folder (the zip should contain the folder, with `SKILL.md` inside it) and upload it in Claude's settings under Skills. Then type `/ig-plan` (or just ask "plan my Instagram week") in any chat.

## Edit your niche
Every `SKILL.md` has an "Account context" block at the top. Change it there if your bio or niche changes, or just tell Claude in the chat.

## Rules these skills follow
You post everything yourself. No bots, auto-comments or mass DMs: Instagram restricts accounts for that.
